# Requirement style

This page states the rule set for the items of an assignment, the document that hands the full in-scope substance of the intent to its recipients. It is for the reader who writes or checks such items and wants the rules exactly.

## The rules

Modal wording:

- Items use **shall** and **shall not**.
- Items do not use would, could, should, might or may.
- Items do not use MoSCoW wording.

Priority:

- An assignment has no priority column and no priority tags.
- Everything in an assignment is essential by default.
- An exception is marked by a note reading *optional* on that item.

Form of an item:

- Each item covers one idea.
- Each item is written once.
- Each item is written in full, correct sentences.

Testability:

- Testability is recommended, not required.
- Assignments are deliberately high-level.
- Delegating concretisation through a deliverable (`DEL`) item is a legitimate outcome.

Terms:

- Defined terms are capitalised in item text.
- The capital signals that the term appears in the Terms section.

Independence:

- An item must not depend on an external link to be understood, agreed or later tested.

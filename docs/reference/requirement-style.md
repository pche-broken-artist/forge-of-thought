# Requirement style

This page lists the rules for writing the items of an assignment. It is for anyone who writes or reviews an assignment and wants the rules in one place.

## The rules

| Rule | What it says |
|---|---|
| Verbs | Items use **shall** and **shall not**. |
| Banned words | would, could, should, might, may, and MoSCoW wording. |
| Priorities | There is no priority column and there are no priority tags. Everything in an assignment is essential by default. |
| Exceptions | An item that is an exception carries a note reading *optional*. |
| One idea | Each item covers one idea. |
| Written once | Each item is written once. |
| Sentences | Each item is written in full, correct sentences. |
| Testability | Recommended, not required. Assignments are deliberately high-level, and handing the concretisation to the recipients through a deliverable item is a legitimate outcome. |
| Defined terms | Terms defined in the Terms section are capitalised in item text, to signal that they appear there. |
| External links | An item must not depend on an external link to be understood, agreed or later tested. |

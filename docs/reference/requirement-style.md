# Requirement style

The requirement style is the rule set for writing the items of an assignment. It is for the reader who writes or checks an assignment and wants the rules exactly as they stand.

## The rules

- Use **shall** and **shall not**.
- Do not use would, could, should, might, may or MoSCoW wording.
- Carry no priority column and no priority tags. Everything in an assignment is essential by default.
- Mark an exception by a note reading *optional* on that item.
- Cover one idea in each item.
- Write each item once.
- Write each item in full, correct sentences.
- Testability is recommended, not required. Assignments are deliberately high-level, and delegating concretisation through a deliverable item is a legitimate outcome.
- Capitalise defined terms in the item text. The capital signals that the term appears in the Terms section.
- An item must not depend on an external link to be understood, agreed or later tested.

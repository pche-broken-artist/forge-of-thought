# Repository layout

The repository layout is the list of the files and folders of the engine root, of a thought project and of a library, each with what it is. It is for anyone who needs to know where a file lives: the user, the extender and the evaluator. A project is a repository of its own, as [Projects and the engine](../about/projects-and-the-engine.md) says. Terms of the forge are in the [Glossary](glossary.md). Wherever "the principal" appears, it means the person whose thinking is forged.

## The engine root

| Path | What it is |
|---|---|
| `CLAUDE.md` | the universal core |
| `CLAUDE.local.md` | the instance facts |
| `README.md` | for humans; a render made by `/render readme` |
| `RELEASE-NOTES.md` | the release notes; a render made by `/render release-notes`; its shape is `templates/recipe-release-notes.md` |
| `CONTRIBUTING.md` | for a visitor who wants to say, ask or change something; a render made by `/render contributing` |
| `docs/` | the documentation, generated by `/document`: pages of one topic each and their index, made from the documentation map `docs-map.md` that lies beside the owning project's ledger |
| `docs/videos/` | the public folder of the projects' html-player files and of the player page `index.html`, written from `templates/html-player.html` by `md2video` |
| `docs/.nojekyll` | keeps GitHub Pages from touching the folder |
| `logo.png` | the project avatar |
| `LICENSE` | CC BY 4.0; the engine is published under attribution |
| `.gitattributes` | the engine's own ways of merging by path, for its derived files at the root and under `projects/forge/` |
| `scripts/` | the scripts and their shared modules (below) |
| `tmp/` | the engine's working folder (below) |
| `.claude/` | skills, agents and settings (below) |
| `templates/` | canonical skeletons |
| `projects/` | gitignored (`projects/*`) except `projects/forge`; every other project is a git repository of its own, which the engine does not know |

The modules the scripts share are `forge_repos`, `forge_tools`, `forge_docs`, `docs_map` and `forge_check`.

### tmp/

`tmp/` is the engine's working folder. It holds these:

- packets, envelopes and profiles of runs on another engine (`tmp/research/<run>/`)
- the tasks of a documentation run
- dry ledgers
- the manifest of a migration
- check reports before filing

The folder is in git with its own `README.md` and `.gitignore`; its contents never are. It is no source of truth and is read by no check, ledger or history.

## A library

A library is `projects/lib-<name>/` and has the kind "library": material shared across projects, with no chain. It has only the project file, the attributes, the ignore of the ledger, sources and research. Its documents are maintained by their owner. Its README is the catalogue, a render of its recipe.

| Path | What it is |
|---|---|
| `.git/` | the library's own repository |
| `project.md` | the project file |
| `.gitattributes` | the attributes |
| `.gitignore` | the ignore of the ledger |
| `ledger.md` | the ledger |
| `README.md` | the catalogue, a render of its recipe |
| `logo.png` | the avatar |
| `recipes/readme.md` | the README's recipe |
| `recipes/readme.history.md` | the recipe's history |
| `sources/00-INDEX.md` | the sources' resource index |
| `research/00-INDEX.md` | the research's resource index |

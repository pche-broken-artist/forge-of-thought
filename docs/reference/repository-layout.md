# Repository layout

This page lists the files and folders of the engine root, of a thought
project and of a library, one line each, for the user, the extender
and the evaluator. Terms of the forge are listed in the
[Glossary](glossary.md). Why every project is a repository of its own
is told in [Projects and the engine](../about/projects-and-the-engine.md).

A render is a document generated from the chain by a recipe and never
edited by hand. The ledger is the file that holds the state of a
project; it is made at read time and is never in git.

## The engine root

| Path | What it is |
|---|---|
| `CLAUDE.md` | The universal core of the forge. |
| `CLAUDE.local.md` | The facts of the instance (see the opening section of `CLAUDE.md`). |
| `README.md` | For humans; a render (`/render readme`). |
| `RELEASE-NOTES.md` | The release notes; a render (`/render release-notes`). Its shape is `templates/recipe-release-notes.md`. |
| `CONTRIBUTING.md` | For a visitor who wants to say, ask or change something; a render (`/render contributing`). |
| `docs/` | The documentation, generated by `/document`: pages of one topic each and their index, made from the documentation map `docs-map.md` that lies beside the owning project's ledger. |
| `docs/videos/` | The public folder of the projects' html-player files and of the player page `index.html`, written from `templates/html-player.html` by `md2video`. |
| `docs/.nojekyll` | Keeps GitHub Pages from touching the documentation. |
| `logo.png` | The project avatar. |
| `LICENSE` | CC BY 4.0; the engine is published under attribution. |
| `.gitattributes` | The engine's own ways of merging by path, for its derived files at the root and under `projects/forge/`. |
| `scripts/` | The scripts and the modules they share (below). |
| `tmp/` | The engine's working folder (below). |
| `.claude/` | Skills, agents and settings (below). |
| `templates/` | Canonical skeletons. |
| `projects/` | Gitignored (`projects/*`) except `projects/forge`. Every other project is a git repository of its own, which the engine does not know. |

The modules the scripts share are `forge_repos`, `forge_tools`,
`forge_docs`, `docs_map` and `forge_check`.

### tmp/

`tmp/` is the engine's working folder. It holds the packets, envelopes
and profiles of runs on another engine (`tmp/research/<run>/`), the
tasks of a documentation run, dry ledgers, the manifest of a migration
and check reports before they are filed. The folder is in git with its
own README and `.gitignore`; its contents are never in git. It is no
source of truth and is read by no check, ledger or history.

## A thought project

A thought project (`kind: thought`) is the chain. It lives in
`projects/<slug>/`.

| Path | What it is |
|---|---|
| `.git/` | The project's own repository. |
| `.gitattributes` | The ways of merging by path (`templates/gitattributes`). |
| `.gitignore` | Holds the ledger, which is made at read time. |
| `README.md`, `RELEASE-NOTES.md` | Renders. |
| `docs-map.md`, `docs/` | The documentation and its map. |
| `logo.png` | Optional project avatar. |
| `project.md` | The project file: slug, kind, language. |
| `00-brief.md`, `10-intent.md` | The trunk of every project. |
| `NN-<layer>.md` | Layers below the intent, as the project needs them. |
| `threads/THR.NNNN.md` | The project's threads, one file each, open and closed. |
| `00-brief-<name>.md` | Later briefs, one per whole. |
| `<file>.history.md` | The history companion of a versioned document. |
| `<file>.history.archive.md` | A history table from before the log; immutable. |
| `decisions.md` | The decisions. |
| `ledger.md` | The ledger. |
| `ledger.archive.md` | The hand-kept ledger at the migration; immutable. |
| `CLAUDE.md` | Optional project-specific polish. Claude Code's `/export` writes into the working directory, so export outside the project or gitignore it. |

## A library

A library (`projects/lib-<name>/`, `kind: library`) holds material
shared across projects and has no chain. Only the project file, the
attributes, the ignore of the ledger, sources and research are the
forge's; the documents are maintained by their owner. Its README is the
catalogue and a render of its recipe.

| Path | What it is |
|---|---|
| `.git/` | The library's own repository. |
| `project.md` | The project file. |
| `.gitattributes` | The ways of merging by path. |
| `.gitignore` | Holds the ledger. |
| `ledger.md` | The ledger. |
| `README.md` | The catalogue. |
| `logo.png` | Project avatar. |
| `recipes/readme.md` | The recipe of the README. |
| `recipes/readme.history.md` | The recipe's history. |
| `sources/00-INDEX.md` | The resource index of the sources. |
| `research/00-INDEX.md` | The resource index of the research. |

# Repository layout

This page lists the files and folders of the engine root, of a thought project and of a library, one line each. It is for anyone who needs to know where a file lives and what it is. The engine is the repository that holds the forge's commands, skills, scripts and templates. A project is a repository of its own under `projects/`. The ledger is the state report that the forge makes from the documents at read time. The principal is the person whose thinking is forged.

## The engine root

| Path | What it is |
|---|---|
| `CLAUDE.md` | The universal core. |
| `CLAUDE.local.md` | The instance facts. |
| `README.md` | The file for humans, a render of the readme recipe. |
| `RELEASE-NOTES.md` | The release notes, a render of the release-notes recipe. The shape is in `templates/recipe-release-notes.md`. |
| `CONTRIBUTING.md` | The file for a visitor who wants to say, ask or change something, a render of the contributing recipe. |
| `docs/` | The documentation, generated by `/document`: pages of one topic each and their index, made from the documentation map `docs-map.md`, which lies beside the owning project's ledger. |
| `docs/videos/` | The public folder of the projects' html-player files and of the player page `index.html`, which `md2video` writes from `templates/html-player.html`. |
| `docs/.nojekyll` | Keeps GitHub Pages from touching the documentation. |
| `logo.png` | The project avatar. |
| `LICENSE` | CC BY 4.0. The engine is published under attribution. |
| `.gitattributes` | The engine's own ways of merging by path, for its derived files at the root and under `projects/forge/`. |
| `scripts/` | The scripts. See the next table. |
| `tmp/` | The engine's working folder. |
| `.claude/` | Skills, agents and settings. |
| `templates/` | The canonical skeletons. |
| `projects/` | Gitignored (`projects/*`) except `projects/forge`. Every other project is a git repository of its own, which the engine does not know. |

### `tmp/`

`tmp/` holds the packets and envelopes of runs on another engine (`tmp/research/<run>/`), the tasks of a documentation run, dry ledgers and check reports before filing. The folder is in git with its own README and `.gitignore`; its contents never are. It is no source of truth and is read by no check, ledger or history.

### `.claude/`

| Part | What it holds |
|---|---|
| skills | The commands, the contracts of the reviewers and of the documentation agents, and the walkthrough method. |
| agents | The reviewers, and the documentation's planner and writer. |
| settings | `settings.json`: the two hooks and the deny rule of the other shell. `settings.local.json`: the session model, gitignored. |

| `forge-ledger` | The ledger, made at read time. |

| `forge-engine` | One packet run on a model of another family over its command-line tool, the answer back as a note. |

| `md2pptx` | Deck render to PowerPoint. |

| `md2video` | Screenplay render to video or player events. |
| `hook-walkthrough` | The per-prompt hook of `.claude/settings.json`. |
| `hook-git` | The wall between reading git and writing it, a PreToolUse hook of the same file. |
| `docs-state`, `docs-index`, `docs-check` | The documentation: the state of its pages, its index, its check. |
| `forge_repos`, `forge_tools`, `forge_docs`, `docs_map` | The modules the scripts share. |

`md2pptx` and `md2docx` each work by pandoc or by a model.

## A thought project

A thought project lives in `projects/<slug>/`. Its kind is thought: it holds the chain.

### Repository files

| Path | What it is |
|---|---|
| `.git/` | The project's own repository. |
| `.gitattributes` | The ways of merging by path, from `templates/gitattributes`. |
| `.gitignore` | Holds the ledger, which is made at read time. |
| `README.md`, `RELEASE-NOTES.md` | Renders. |
| `docs-map.md`, `docs/` | The documentation and its map. |
| `logo.png` | Optional project avatar. |
| `project.md` | The project file: slug, kind, language. |
| `CLAUDE.md` | Optional project-specific polish. Claude Code's `/export` writes into the working directory, so export outside the project or gitignore the export. |

### The chain and its records

| Path | What it is |
|---|---|
| `00-brief.md`, `10-intent.md` | The trunk of every project. |
| `NN-<layer>.md` | Layers below the intent, as the project needs them. |
| `00-brief-<name>.md` | Later briefs, one per whole. |
| `threads/THR.NNNN.md` | The project's threads, one file each, open and closed. |
| `<file>.history.md` | The history companion of a versioned document. |
| `<file>.history.archive.md` | A history table before the log, immutable. |
| `decisions.md` | The decisions. |
| `ledger.md` | The ledger. |
| `ledger.archive.md` | The hand-kept ledger at the migration, immutable. |

### Resources

| Path | What it is |
|---|---|
| `sources/00-INDEX.md` | Resource index, rewritten. |
| `sources/<name>.<ext>` | Immutable external inputs, one form each: a `<slug>.md` extract of a binary, or the binary itself. |
| `sources/.gitignore` | Originals converted in place. |
| `sources/<slug>/` | A bundle of related files: one source, one ledger entry, catalogued by its `00-INDEX.md`. |
| `research/00-INDEX.md` | Resource index, rewritten. |
| `research/YYYY-MM-DD-<topic>.md` | Immutable research note. |
| `research/YYYY-MM-DD-<topic>/` | A research of several questions: a bundle. |
| `research/YYYY-MM-DD-<topic>/00-plan.md` | The plan and the synthesis. |
| `research/YYYY-MM-DD-<topic>/<card>.<engine>.md` | One note per card per engine. |

### Renders, published files and work

| Path | What it is |
|---|---|
| `recipes/<recipe>.md` | Render recipes: inputs, audience, instructions, template. Iterated. |
| `recipes/<recipe>.history.md` | The recipe's history. |
| `renders/<recipe>.md` | Generated output, overwritten by `/render`, with provenance front-matter. |
| `renders/<recipe>.<lang>.md` | One render per language, where the recipe declares languages. |
| `renders/<recipe>.pptx`, `renders/<recipe>.docx` | The plain file of a render, made by `/render` through pandoc where the recipe names a format. |
| `renders/<recipe>.<lang>.mp4`, `renders/<recipe>.<lang>.html-player.js` | The plain file of a screenplay, made by `md2video`; or in the engine's `docs/videos/` by `output:`. |
| `renders/state.md` | The ledger as a render, written by `/release` on `main`. |
| `published/<recipe>.pptx`, `published/<recipe>.docx` | The designed file, made by `/publish` through a model. |
| `published/<recipe>.md` | The companion: the provenance of the published file (step 6 of `/publish`), read by the Published table. |
| `work/<name>.spec.md` | A work product: the specification, the way and the why. |
| `work/<name>.spec.history.md` | The history of the specification. |
| `work/<name>.<ext>` | The file, the content. |

### Review reports

| Path | What it is |
|---|---|
| `reviews/YYYY-MM-DD-critique-<lens>-HHMM-<hash>.md` | Immutable critique runs. The name is completed by `forge-report`. |
| `reviews/YYYY-MM-DD-check-<name>-HHMM-<hash>.md` | Immutable check reports, filed when a check finds something. |
| `challenges/YYYY-MM-DD-challenge-<persona>-HHMM-<hash>.md` | Immutable peer reviews. |

## A library

A library lives in `projects/lib-<name>/`. Its kind is library: material shared across projects, with no chain. Only the project file, the attributes, the ignore of the ledger, sources and research are kept; documents are maintained by their owner.

| Path | What it is |
|---|---|
| `.git/` | The library's own repository. |
| `project.md` | The project file. |
| `.gitattributes` | The attributes. |
| `.gitignore` | The ignore of the ledger. |
| `ledger.md` | The ledger. |
| `README.md` | The catalogue, a render of its recipe. |
| `logo.png` | The avatar. |
| `recipes/readme.md` | The recipe of the README. |
| `recipes/readme.history.md` | The history of that recipe. |
| `sources/00-INDEX.md` | Resource index. |
| `research/00-INDEX.md` | Resource index. |

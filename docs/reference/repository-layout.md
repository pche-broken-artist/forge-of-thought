# Repository layout

This page lists the layout of the engine root, of a thought project and of a library, file by file, for anyone who needs to know where a file lives and what it is. The terms of the forge are one line each in the [Glossary](glossary.md). Why every project is a repository of its own is told in [Projects and the engine](../about/projects-and-the-engine.md).

## The engine root

| Path | What it is |
|---|---|
| `CLAUDE.md` | The universal core of the forge. |
| `CLAUDE.local.md` | The instance facts, described in the core as "What this workspace is". |
| `README.md` | For humans. It is a render, made by `/render readme`. |
| `RELEASE-NOTES.md` | The release notes. It is a render, made by `/render release-notes`. Its shape is `templates/recipe-release-notes.md`. |
| `CONTRIBUTING.md` | For a visitor who wants to say, ask or change something. It is a render, made by `/render contributing`. |
| `docs/` | The documentation, generated by `/document`: pages of one topic each and their index, made from the documentation map `docs-map.md` that lies beside the owning project's ledger. |
| `docs/videos/` | The public folder of the projects' html-player files and of the player page `index.html`. The page is written from `templates/html-player.html` by `md2video`. |
| `docs/.nojekyll` | Keeps GitHub Pages from touching `docs/videos/`. |
| `logo.png` | The project avatar. |
| `LICENSE` | CC BY 4.0. The engine is published under attribution. |
| `scripts/` | The scripts, listed below. |
| `.claude/` | Skills, agents and settings, listed below. |
| `templates/` | The canonical skeletons. |
| `projects/` | Gitignored (`projects/*`) except `projects/forge`. Every other project is a git repository of its own, which the engine does not know. |

### What `scripts/` holds

| Script | What it is for |
|---|---|
| `forge-save`, `forge-pull`, `forge-status`, `forge-clone`, `forge-branch` | Git. |
| `forge-history` | The history of one item. |
| `doc2md` | Document to Markdown. |
| `md2pptx` | Deck render to PowerPoint, each by pandoc or by a model. |
| `md2docx` | Render to Word, each by pandoc or by a model. |
| `md2video` | Screenplay render to video or to player events. |
| `hook-walkthrough` | The per-prompt hook of `.claude/settings.json`. |
| `docs-state`, `docs-index`, `docs-check` | The documentation: the state of its pages, its index and its check. |
| `docs_map` | The shared reader of the documentation map. |

### What `.claude/` holds

| Part | What it is |
|---|---|
| skills | The commands, the contracts of the reviewers and of the documentation agents, and the walkthrough method. |
| agents | The reviewers, and the documentation's planner and writer. |
| settings | `settings.local.json` holds the session model and is gitignored. |

## A thought project: `projects/<slug>/`

A thought project is of kind thought: it holds the chain.

| Path | What it is |
|---|---|
| `.git/` | The project's own repository. |
| `README.md`, `RELEASE-NOTES.md` | Renders. |
| `docs-map.md`, `docs/` | The documentation and its map. |
| `logo.png` | Optional project avatar. |
| `00-brief.md`, `10-intent.md` | The trunk of every project. |
| `NN-<layer>.md` | Layers below the intent, as the project needs them. |
| `threads.md` | The project's open threads, as the definition of the intent has them. |
| `00-brief-<name>.md` | Later briefs, one per whole. |
| `<file>.history.md` | The history companion of a versioned document. |
| `<file>.history.archive.md` | A history table from before the log. It is immutable. |
| `decisions.md`, `ledger.md` | The decisions and the ledger. The ledger header carries the kind. |
| `sources/00-INDEX.md` | The resource index of the sources. It is rewritten. |
| `sources/<name>.<ext>` | Immutable external inputs, one form each: a `<slug>.md` extract of a binary, or the binary itself. |
| `sources/.gitignore` | Originals converted in place. |
| `sources/<slug>/` | A bundle of related files. It counts as one source with one ledger entry and is catalogued by its own `00-INDEX.md`. |
| `research/00-INDEX.md` | The resource index of the research. It is rewritten. |
| `recipes/<recipe>.md` | Render recipes: inputs, audience, instructions and template. They are iterated. |
| `recipes/<recipe>.history.md` | The recipe's history. |
| `renders/<recipe>.md` | Generated outputs, overwritten by `/render`, with provenance front-matter. |
| `renders/<recipe>.<lang>.md` | One render per language, where the recipe declares languages. |
| `renders/<recipe>.pptx`, `renders/<recipe>.docx` | The plain file of a render, made by `/render` through pandoc where the recipe names a format. |
| `renders/<recipe>.<lang>.mp4`, `renders/<recipe>.<lang>.html-player.js` | The plain file of a screenplay, made by `md2video`. With `output:` it lands in the engine's `docs/videos/` instead. |
| `published/<recipe>.pptx`, `published/<recipe>.docx` | The designed file, made by `/publish` through a model. |
| `work/<name>.spec.md`, `work/<name>.spec.history.md` | A work product: the specification, the way and the why, with its history. |
| `work/<name>.<ext>` | A work product: the file, the content. |
| `reviews/YYYY-MM-DD-critique-<lens>.md` | Immutable critique runs. |
| `reviews/YYYY-MM-DD-check-<name>.md` | Immutable check reports, filed when a check finds something. |
| `challenges/YYYY-MM-DD-challenge-<persona>.md` | Immutable peer reviews. |
| `research/YYYY-MM-DD-<topic>.md` | Immutable research notes. |
| `CLAUDE.md` | Optional project-specific polish. Claude Code's `/export` writes into the working directory, so export outside the project or gitignore it. |

## A library: `projects/lib-<name>/`

A library is of kind library: material shared across projects, with no chain, only the ledger, the sources and the research. Its documents are maintained by their owner. Its README is the catalogue, a render of its recipe.

| Path | What it is |
|---|---|
| `.git/` | The library's own repository. |
| `ledger.md` | The ledger. |
| `README.md` | The catalogue, a render of the recipe. |
| `logo.png` | Project avatar. |
| `recipes/readme.md` | The recipe of the README. |
| `recipes/readme.history.md` | The history of that recipe. |
| `sources/00-INDEX.md` | The resource index of the sources. |
| `research/00-INDEX.md` | The resource index of the research. |

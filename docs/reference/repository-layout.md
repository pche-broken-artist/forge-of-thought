# Repository layout

This page lists the files and folders of the engine root, of a thought project and of a library, one line each, for the user, the extender and the evaluator. A thought project is a project with a chain of documents; a library is a project that holds shared material and has no chain. Terms of the forge are in the [Glossary](glossary.md). Why every project is a repository of its own is in [Projects and the engine](../about/projects-and-the-engine.md).

## The engine root

| Path | What it is |
|---|---|
| `CLAUDE.md` | The universal core: the rules of the forge. |
| `CLAUDE.local.md` | The facts of one instance (who the principal is, the conversation language, the handle used to sign records). The principal is the person whose thinking is forged. |
| `README.md` | For humans. A render, made by `/render readme`. |
| `RELEASE-NOTES.md` | The release notes. A render, made by `/render release-notes`; its shape is `templates/recipe-release-notes.md`. |
| `CONTRIBUTING.md` | For a visitor who wants to say, ask or change something. A render, made by `/render contributing`. |
| `docs/` | The documentation, generated by `/document`: pages of one topic each and their index, made from the documentation map `docs-map.md`, which lies beside the owning project's ledger. |
| `docs/videos/` | The public folder of the projects' html-player files and of the player page `index.html`, which `md2video` writes from `templates/html-player.html`. |
| `docs/.nojekyll` | Keeps GitHub Pages from touching the folder. |
| `logo.png` | The project avatar. |
| `LICENSE` | CC BY 4.0. The engine is published under attribution. |
| `.gitattributes` | The engine's own ways of merging by path, for its derived files at the root and under `projects/forge/`. |
| `scripts/` | The scripts and their shared modules; see below. |
| `tmp/` | The engine's working folder; see below. |
| `.claude/` | Skills, agents and settings; see below. |
| `templates/` | Canonical skeletons. |
| `projects/` | Gitignored (`projects/*`) except `projects/forge`. Every other project is a git repository of its own, which the engine does not know. |

### scripts/

|---|---|

| `forge-history` | The history of one item. |

| `forge-ledger` | The ledger, made at read time. |

| `md2docx` | Render to Word, by pandoc or by a model. |
| `md2video` | Screenplay render to video or player events. |
| `hook-walkthrough` | The per-prompt hook of `.claude/settings.json`. |
| `hook-git` | The wall between reading git and writing it; a PreToolUse hook of the same file. |

| `docs-index` | The index of the documentation. |
| `docs-check` | The check of the documentation. |

Five modules are shared by the scripts: `forge_repos`, `forge_tools`, `forge_docs`, `docs_map` and `forge_check`.

### tmp/

The engine's working folder. It holds:

- packets, envelopes and profiles of runs on another engine (`tmp/research/<run>/`)
- the tasks of a documentation run
- dry ledgers
- the manifest of a migration
- check reports before they are filed

The folder is in git with its own README and `.gitignore`; its contents are never in git. It is no source of truth and is read by no check, ledger or history.

### .claude/

- skills: the commands, the contracts of the reviewers and of the documentation agents, and the walkthrough method
- agents: the reviewers, and the planner and the writer of the documentation
- settings: `settings.json` holds the two hooks and the deny rule of the other shell; `settings.local.json` holds the session model and is gitignored

## A thought project

A thought project lives in `projects/<slug>/`.

| Path | What it is |
|---|---|
| `.git/` | The project's own repository. |
| `.gitattributes` | The ways of merging by path, from `templates/gitattributes`. |
| `.gitignore` | What never enters git: the ledger and the Office lock files. From `templates/gitignore`. |
| `README.md`, `RELEASE-NOTES.md` | Renders. |
| `docs-map.md`, `docs/` | The documentation and its map. |
| `logo.png` | Optional project avatar. |
| `project.md` | The project file: slug, kind, language. |
| `00-brief.md`, `10-intent.md` | The trunk of every project. |
| `NN-<layer>.md` | Layers below the intent, as the project needs them. |
| `threads/THR.NNNN.md` | The project's threads, one file each, open and closed. |
| `00-brief-<name>.md` | Later briefs, one per whole. |
| `<file>.history.md` | The history companion of a versioned document. |
| `<file>.history.archive.md` | A history table from before the log; immutable. |
| `decisions.md` | The decisions. |
| `ledger.md` | The ledger. |
| `ledger.archive.md` | The hand-kept ledger at the migration; immutable. |
| `CLAUDE.md` | Optional project-specific polish. Claude Code's `/export` writes into the working directory, so export outside the project or gitignore the export. |

## A library

A library lives in `projects/lib-<name>/`. It holds material shared across projects and has no chain: only the project file, the attributes, the ignore of the ledger, sources and research. Its documents are maintained by their owner. Its README is the catalogue, a render of its recipe.

| Path | What it is |
|---|---|
| `.git/` | The library's own repository. |
| `project.md` | The project file. |
| `.gitattributes` | The ways of merging by path. |
| `.gitignore` | What never enters git. |
| `ledger.md` | The ledger. |
| `README.md` | The catalogue. |
| `logo.png` | The avatar. |
| `recipes/readme.md` | The recipe of the README. |
| `recipes/readme.history.md` | The recipe's history. |
| `sources/00-INDEX.md` | The resource index. |
| `research/00-INDEX.md` | The resource index. |
